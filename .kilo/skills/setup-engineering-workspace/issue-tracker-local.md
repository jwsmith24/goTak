# Issue tracker: local Markdown

Issues and specs live under `.scratch/<feature>/`:

- `spec.md` is the feature specification.
- `issues/NN-slug.md` holds one implementation ticket per file.
- `Status:` records triage or wayfinding state.
- append discussion under `## Comments` without rewriting history.

Preview paths and complete content before creating or editing files. Obtain explicit authorization for each proposed batch, re-read existing destinations, preserve user edits, and stop on concurrent changes. Local tracker approval does not authorize Git operations or remote publication.
