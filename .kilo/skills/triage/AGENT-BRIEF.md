# Durable implementation brief

Describe behavioral contracts rather than volatile line numbers or implementation steps. Include:

```markdown
## Agent brief

**Category:** bug | enhancement
**Summary:** <one line>

## Current behavior
<Observed status quo and evidence.>

## Desired behavior
<Behavior, edge cases, and errors.>

## Key interfaces
- <Durable interface/type/config contract>

## Acceptance criteria
- [ ] <Independently verifiable outcome>

## Out of scope
- <Explicit boundary>
```

For a merge request, current behavior describes its diff and desired behavior describes the work remaining. State why a `ready-for-human` brief requires human judgment or access.
