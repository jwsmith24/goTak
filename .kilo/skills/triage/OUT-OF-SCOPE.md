# Out-of-scope records

Store one `.out-of-scope/<concept>.md` per durably rejected enhancement concept. Explain the scope, technical, or strategic reason and list prior requests. Match new requests by concept, not keywords.

Before creating a file, search for a matching concept. Append a reference when one exists. Preview creation, append, rewrite, or deletion and obtain authorization; preserve concurrent edits. Do not record bugs, temporary deferrals, or requests closed because behavior already exists.
