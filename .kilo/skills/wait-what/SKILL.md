# Wait, what?

Re-pitch the immediately preceding message:

1. Add the context needed to understand where the conversation has reached and why.
2. Use ASD-STE100 Simplified Technical English: short, direct sentences; one instruction or idea at a time; concrete and consistent terms.
3. Use the project's ubiquitous language from `CONTEXT.md` when that file exists. If the repository has more than one context document, follow `CONTEXT-MAP.md` when it exists to select the relevant one.
4. Preserve the original meaning. Explain it rather than advancing the work or taking new actions.
